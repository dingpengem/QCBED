# Historical architecture provenance

The Python package descends from an earlier multislice implementation. Private
source review informed the separation of input parsing, sample construction,
propagation, objective evaluation and optimization. Shared development guidance
is in [Architecture](ARCHITECTURE.md) and [source provenance](source_provenance.md).

Preserve units, coordinate conventions, Fourier signs, normalization, ordering and
boundary conditions. Numerical-reference data and executable comparisons, rather
than historical source listings, establish the scope of validated behavior.

Legacy implementation sources and detailed source inventories are maintained privately and are not distributed with this repository.
